# Сторонние зависимости

| Библиотека | Назначение | Лицензия |
|---|---|---|
| [gozxing](https://github.com/makiuchi-d/gozxing) | декодирование QR-кодов | Apache-2.0 / MIT |
| [snowball](https://github.com/kljensen/snowball) | стемминг русских слов | MIT |
| [pgx](https://github.com/jackc/pgx) | драйвер PostgreSQL | MIT |
| [goose](https://github.com/pressly/goose) | миграции схемы | MIT |
| [telebot](https://github.com/tucnak/telebot) | клиент Telegram Bot API | MIT |
| [env](https://github.com/caarlos0/env) | конфигурация из окружения | MIT |
| [testcontainers-go](https://github.com/testcontainers/testcontainers-go) | PostgreSQL в тестах | MIT |

Все перечисленные лицензии разрешают использование в открытых и закрытых
проектах при сохранении текста лицензии и уведомлений об авторстве.
Полные тексты доступны в репозиториях библиотек и в module cache Go.
